## 零、先说结论：顺序错了会白干

推广前必须先解决一个硬伤。现在的购买漏斗是：

```
看到 → 落地页 → 相信 → 付款 → 才第一次见到软件
```

**缺了「体验」这一环。** 陌生人要在完全没见过软件长什么样、不知道解析成不成功的情况下先掏钱，
¥19 也不贵，但这一步的心理门槛远高于价格本身。

所以正确的顺序是：

| 顺序 | 动作 | 状态 |
|---|---|---|
| ① | **补免费试用** | ✅ 已完成（v2.2，见第一节） |
| ② | 铺内容渠道，吃长尾搜索流量 | 🟡 成稿已备，待发布（见第三节 + `成稿/` 四份文件） |
| ③ | 上交易平台，吃主动搜索流量 | ⬜ 待做（见第三节，第 4 周） |

跳过 ① 直接做 ②③，等于往漏水的桶里灌水——流量来了，转化率会低到让你误判"渠道不行"。

## 一、卡点：补一个免费试用

### 1.1 现状（代码证据）

`qt_app.py:2159` 的注释和 `main()` 逻辑：

```python
# 未激活或已过期则先弹激活窗口，取消/失败即退出，不进入主界面
if not activation.is_activated():
    ...
    if dlg.exec() != QDialog.Accepted:
        return 0
```

未激活 → 弹激活框 → 取消就退出。买家下载完 58MB 安装包，装好，双击，
看到的是一个要钱的框，什么都试不了。

### 1.2 建议方案：每日 3 次免费解析

| 项 | 规则 |
|---|---|
| 免费额度 | 每天 3 次解析（单视频 / 主页均可，主页一次算一次） |
| 重置方式 | 按自然日，本地记 `试用日期 + 当天已用次数` |
| 功能范围 | **不阉割**。免费和付费解析出的东西完全一样 |
| 超限提示 | 「今日免费额度已用完，激活后无限使用」+ 直达购买页按钮 |
| 界面标识 | 标题栏显示「（试用 · 今日剩 N 次）」 |

**为什么不阉割功能：** 试用是为了让买家确认"这玩意儿真能用"。
如果试用版解析出来是低画质或者带水印，买家只会得出"这软件不行"的结论，
比不给试用更糟。

**为什么是 3 次而不是 7 天：** 下载器的需求是脉冲式的——想存某个视频时打开，
存完就关。按次数给比按天给更贴合真实使用节奏，也不会让人觉得"反正能免费用一周，不急"。

### 1.3 已实现（v2.2，2026-10-18）

改动落在三个地方：

| 文件 | 改动 |
|---|---|
| `activation.py` | 新增 `trial_left()` / `trial_consume()` / `trial_path()` / `trial_state()`；计数存 `%APPDATA%\DouyinParser\trial.dat`，格式 `日期\t已用次数` |
| `qt_app.py` | `main()` 的拦截条件从「未激活」改为「`trial_left() == 0`」；两个解析入口先扣额度再校验 Cookie；标题栏实时显示剩余次数；配置页新增「授权」区（填入激活码 / 购买激活） |
| `activation.example.py` | 同步试用代码（公开仓库里给外人用的那份，不同步会 `AttributeError`）；顺带修了它一个历史 bug |

验证覆盖（隔离到临时目录跑的，没动真实授权状态）：

- 全新用户 3 次 → 扣完 → 第 4 次拦下
- 跨自然日自动重置
- **系统时间往回调不刷新额度**（防改时钟白嫖）
- 激活后 `trial_left()` 返回 -1（不限次）
- 打包产物里确认 `activation` / `qt_app` 均含试用代码与文案常量

顺手修的历史 bug：`activation.example.py` 里 `SECRET = b"CHANGE-ME-请填入…"` ——
bytes 字面量不能含中文，外人克隆下来一跑就是 `SyntaxError`。已改成 ASCII 占位
并附上生成私钥的命令。

## 二、合规红线（必须先看清，不然号没了）

这个品类的推广有真实风险，以下不是免责声明，是会实际发生的后果。

### 2.1 内容平台的敏感词

| 平台 | 风险 | 应对 |
|---|---|---|
| 小红书 | 「去水印」「搬运」「下载抖音」属于限流词，笔记容易被压曝光甚至屏蔽 | 换角度：**素材管理 / 剪辑工作流 / 对标账号拆解**，正文不出现"去水印"三个字 |
| 抖音 | 站内推站外工具，且是竞品平台的下载器，容易被判"引流" | 视频里不露软件名和网址，引导走主页简介 |
| 知乎 | 相对宽松，但直接贴外链可能被折叠 | 回答里先给足方法价值，链接放在文末，用"我做的工具"自述口吻 |
| B站 | 技术区容忍度高 | 走"技术实现分享"路线，不承诺任何搬运用途 |

### 2.2 收款合规

现在用的是**个人收款码**收经营款项。风险点：

- 微信/支付宝对个人码的**经营性收款**有风控，频次高、金额集中时可能限制收款
- 单笔 ¥160 的终身版走个人码，属于典型的经营行为特征
- **建议**：月流水过千后改用面包多 / 爱发电这类平台收款（平台会处理资质和开票），
  本站的 `pay.mode` 已经预留了 `mbd` 模式，切过去只要填回调地址，业务代码不用动

### 2.3 版权口径（所有文案统一）

统一口径，**所有渠道的文案都按这个来**：

> 本工具仅用于保存你本人创作的内容，或已获得授权的内容。
> 下载的视频受著作权保护，请勿用于二次发布、搬运或任何商业用途。

这条不是走过场——它在文案里出现，既是自我保护，也能筛掉一批"想拿去搬运"的
低质量用户，减少后续纠纷。

## 五、怎么判断推得动不动

后台「渠道效果」卡片看三个数：

- **下单数高、已付数低** → 流量来了但没转化。要么试用没做（回到第一节），
  要么这个渠道来的人只是好奇不是真需求
- **已付数高但成交额低** → 都买月版 ¥19。说明终身版的说服力不够，
  落地页上要把「年版 ¥90 折合每天 0.25 元」这类对比做出来
- **某个渠道持续零转化** → 两周后砍掉，把时间给有效渠道

> 库存四档各 198–200 条。按当前节奏，短期不需要补货。
