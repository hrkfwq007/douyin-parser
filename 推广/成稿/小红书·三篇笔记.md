## 笔记 B · 角度：对标账号拆解

**标题**：拆解对标账号，我的素材归档流程

**正文**：

```
做自媒体最重要的一件事：把对标账号拆明白。

我的做法是建一个本地素材库，按账号归档：

1. 整页拉取对标账号的内容列表
2. 筛出数据明显高出一截的那几条
3. 存原文件 + 记录当时的互动数据
4. 按月回看，看内容方向的变化

关键是第 3 步——光存视频没用，得把数据一起存下来，
不然过两个月你根本想不起来当时为什么存它。

再说个小经验：比起点赞数，我更看收藏/点赞比。
点赞是顺手点的，收藏是有用的才存。
一个点赞 5000 收藏 2000 的，参考价值远大于点赞 1 万收藏 800 的。

我现在用电脑端工具做这件事，粘贴链接就出结果，
数据一并导出，比手动记表格快太多。

#自媒体 #对标拆解 #运营干货 #效率工具
```

## 笔记 C · 角度：数字资产备份

**标题**：自己发的内容，一定要留一份本地备份

**正文**：

```
说个容易忽略的事：你发在平台上的内容，本地不一定有完整备份。

手机换了、账号出问题、原始素材误删——任何一种情况发生，
那些内容就找不回来了。

我吃过这个亏。之前有一批内容原始素材误删，只存在平台上，
后来想重新剪一版，只能从平台重新存，画质还降了一档。

现在我的习惯是每个月把当月发的内容存一份原文件到硬盘，
顺便记一下每条的数据，年底回看特别清楚：

· 一键拉取当月全部作品
· 存原文件，画质不降档
· 图文笔记也一起存
· 数据跟着文件走，不用再翻后台

工具是电脑端的，粘贴自己作品的链接就能存。

#备份 #自媒体 #数字资产 #效率工具
```
