# B站 · 视频脚本

> **标题**：花两周做了个抖音视频解析工具，聊聊踩了哪些坑
> **时长**：6–8 分钟
> **分区**：科技数码 > 软件分享（技术区对新工具接受度最高，别发生活区）
>
> 走「技术实现分享」路线，**不承诺任何搬运用途**，
> 否则容易被判定为违规工具推广。

## 分镜表

| 时间 | 画面 | 口播要点 |
|---|---|---|
| 0:00–0:30 | 成品界面演示，快速过一遍功能 | 「先看看成品：粘链接、解析、下载，三步。图集、主页批量也支持。」 |
| 0:30–1:30 | 讲需求背景 | 「起因是我自己要存素材，发现市面上的工具要么带水印，要么只能存视频拿不到数据。在线解析站我又不敢用——链接要过别人的服务器。」 |
| 1:30–3:30 | 讲技术：短链跳转、登录态 | 「第一个坑：短链不能一把梭跟跳转，中间会插风控页，得逐跳处理，从最后一跳拿 ID。第二个坑：现在不登录拿不到数据，我试过免 Cookie 方案，接口返回空，走不通。」 |
| 3:30–5:00 | 讲请求签名（**只讲思路，不贴实现**） | 「请求要带签名，这块只讲思路：参数是排序后经过混淆生成的，逆向成本主要在定位加密函数——混淆后的 JS 里函数名叫 _0x1a2b 这种，得靠调用栈去锚。」 |
| 5:00–6:30 | 讲体积优化：719MB → 59MB | 「最有意思的是体积。完整版 944MB，其中 Chromium 独占 719MB。后来改成调用系统 Edge，安装包直接降到 59MB，功能一点没少。」 |
| 6:30–7:00 | **讲那个蠢错误**（这段最出彩，别剪掉） | 「但我中间犯了个特别蠢的错：我一开始以为精简版就是把登录砍掉，结果砍完发现——精简版什么也解析不了，因为登录态是硬需求。这是把'精简'和'阉割'搞混了。」 |
| 7:00–7:40 | 演示批量 + 数据导出 | 「主页批量解析，四条互动数据一起导出，做对标分析很方便。记录还会本地保存，误删能恢复。」 |
| 7:40–8:00 | 结尾 | 「是付费软件，下载能先试用。链接在简介。**重申一遍：只用来存自己的或已授权的内容，别拿去搬运。**」 |

## 简介文案（发布时贴进简介框）

```
抖音视频解析工具，Windows 桌面端。
· 单视频 / 图集 / 主页批量解析
· 无水印原文件 + 四项互动数据
· 精简版 59MB，调用系统 Edge / Chrome
· 第一次用需扫码登录一次（抖音接口要求，不登录取不到数据）

下载：https://douyin-parser-42948.app.workbuddy.host/?ref=bili

仅用于保存本人创作或已获授权的内容，请勿用于搬运或二次发布。
```
